# Suvedha S — Developer Portfolio

Responsive portfolio customized around the supplied resume. Built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Included
- Professional portrait hero section and responsive navigation
- Interactive portrait zoom in/out and font-size controls
- Hover glow, reveal-on-scroll and animated gradient effects
- About, skills, experience, projects, education and contact sections
- Mobile-friendly layout

## Deploy to Vercel
Import this folder's GitHub repository in Vercel. Choose the Other framework preset; no build command is required and the output is the project root.

## Edit content
Update text and links in `index.html`, styling in `assets/style.css`, and interactions in `assets/script.js`.
